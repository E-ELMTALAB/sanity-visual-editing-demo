## 🔧 Customization Options

### Easy to Edit
All text is in plain Persian and can be edited directly. Just search for the section titles:

1. `شریف جی پی تی؛ پیشرو در ارائه خدمات`
2. `چرا استفاده از هوش مصنوعی برای کسب‌وکار`
3. `خدمات و مزایای منحصربه‌فرد شریف جی پی تی`

### Change Colors
Modify the gradient colors in className:
```jsx
// Current: Blue-Purple
from-blue-50 to-purple-50

// Change to: Green-Yellow
from-green-50 to-yellow-50

// Or: Orange-Red
from-orange-50 to-red-50
```

### Adjust Spacing
Modify margin and padding:
```jsx
// Current
className="mb-16 sm:mb-20"  // Bottom margin
p-8 sm:p-12                  // Padding

// Increase spacing
className="mb-24 sm:mb-32"
p-12 sm:p-16
```
