## The Build Process (Complete Flow)

```
npm run build
  ↓
1. prebuild hook runs
   └─→ scripts/cache-sanity-data.ts
       └─→ Fetches from Sanity API
       └─→ Saves to: public/sanity-cache/*.json
       └─→ Generates: public/sanity-cache/index.ts
  ↓
2. Next.js build starts
   └─→ Compiles TypeScript
   └─→ Bundles React components
   └─→ Copies public/ to .next/static/ ✅ (CACHE FILES INCLUDED!)
   └─→ Creates server bundle
  ↓
3. postbuild hook runs
   └─→ verify-cache-build.js
       └─→ Verifies all cache files exist
       └─→ Confirms .next/static has cache
       └─→ Validates deployment readiness
  ↓
4. Build complete! ✅
   └─→ .next/ folder contains:
       ├── static/ (includes public/sanity-cache as static files)
       ├── server/
       └── server.js
  ↓
5. Deploy the .next/ folder (and public/)
   └─→ All cache files included
   └─→ No external dependencies
   └─→ Ready to run anywhere!
```

## Guaranteed Static Serving

### How Next.js Serves Cache Files

When `npm run build` executes:

1. **Source**: `public/sanity-cache/*.json` (generated by prebuild)
2. **Process**: Next.js automatically copies everything from `public/` to `.next/static/`
3. **Serving**: Files are served as static assets (no server processing needed)
4. **URL**: Accessible at `/_next/static/sanity-cache/homepage.json`
5. **Performance**: Served instantly from disk (0ms latency)

## Troubleshooting Deployment

### Issue: Cache not in dist

**Check 1: Cache generated?**
```bash
ls -la public/sanity-cache/
# Should show multiple .json files
```

**Check 2: Build output?**
```bash
ls -la .next/static/sanity-cache/
# Should show same files as public/sanity-cache/
```

**Check 3: Rebuild**
```bash
rm -rf .next
npm run build:verify
```

### Issue: API calls still happening

**Check 1: Production mode?**
```bash
NODE_ENV=production npm start
# MUST be production mode!
```

**Check 2: Cache files exist?**
```bash
test -f .next/static/sanity-cache/homepage.json && echo "✅ Exists"
```

**Check 3: Check imports**
```typescript
// Must use getCachedData, not client.fetch
import { getCachedData } from 'lib/sanity-cache'
const data = getCachedData('homepage')
```

### Issue: Size too large

**Check cache size:**
```bash
du -sh public/sanity-cache/
# Typical: 2-5MB (acceptable)
```

**Reduce cache:**
- Edit `scripts/cache-sanity-data.ts`
- Reduce number of products cached
- Limit blog posts or courses cached
- Remove unnecessary data
