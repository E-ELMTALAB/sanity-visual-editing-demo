🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

1. Install & Run (Local Development):
   $ cd simplified-medusa-backend
   $ npm install
   $ PORT=3000 npm start

2. Test in Another Terminal:
   $ curl http://localhost:3000/products | jq
   $ bash examples.sh

3. Deploy to Liara:
   - Push code to GitHub
   - Create Node.js project in Liara
   - Set env vars: PORT=3000, ADMIN_KEY=..., STRIPE_SECRET_KEY=...
   - Deploy (auto-detects via liara.json)

═══════════════════════════════════════════════════════════════════════════════
💳 PAYMENTS
═══════════════════════════════════════════════════════════════════════════════

Without Stripe (Default):
  - Checkout returns mock payment_url
  - Visit URL to mark order as paid
  - Perfect for testing

With Stripe (Set STRIPE_SECRET_KEY):
  - Checkout returns client_secret
  - Use with Stripe.js for real payments
  - PaymentIntent created on checkout

📊 DATA STRUCTURE
═══════════════════════════════════════════════════════════════════════════════

All data in data.json (no database needed):
  - products: [{id, title, variants[{prices, sku, inventory}], ...}]

Edit directly or use admin endpoints.

═══════════════════════════════════════════════════════════════════════════════
🎯 WHAT'S DIFFERENT FROM MEDUSA
═══════════════════════════════════════════════════════════════════════════════

Simplified backend is SMALLER but compatible:
  
Medusa:                          Simplified:
  ✓ Full e-commerce platform      ✓ Just products + checkout
  ✓ Inventory management          ✓ Inventory per variant
  ✓ Fulfillment system            ✓ Orders only
  ✓ Complex auth                  ✓ Simple admin key
  ✓ Database required             ✓ JSON only
  ✓ Hard to deploy                ✓ Easy (1-click Liara)
  
Both return the SAME response format ✅
Your client code works with both ✅
